# MUC Selection Search
## 选调信息智能检索系统

> 基于学校信息门户的选调经验智能检索平台

---

## 1. 项目简介

本项目为软件工程课程实验三项目。

系统面向校内选调信息检索场景，在实验二已有门户数据采集方案基础上，
进一步实现一个可实际访问和使用的 Web 检索系统。

系统目标不是简单实现“爬虫 + 搜索框”，而是完成：

- 学校信息门户选调经验数据的同步与结构化处理；
- 传统关键词检索；
- AI 自然语言检索；
- 来源和证据追溯；
- 检索结果对比、汇总与导出；
- 不同身份的访问权限控制；
- 用户收藏、关注、搜索历史与个性化能力；
- 数据安全、隐私控制、异常降级与移动端适配。

核心产品原则：

**可信、有效、省事、可控、可扩展。**

---

## 2. 产品定位

系统提供两种搜索方式，但二者共享同一个底层检索核心。

### 传统搜索

适合明确查找：

- 专业
- 学历
- 届别
- 地区
- 单位
- 岗位
- 关键词

传统检索不会依赖大模型才能工作。

### AI 搜索

用户可以直接输入自然语言，例如：

> 我是计算机专业本科生，想看看去西部基层工作的学长学姐案例。

系统首先理解查询，再调用统一检索服务获得真实资料，
最后由 RAG 基于检索证据生成总结。

AI 不允许凭模型记忆补充资料库中不存在的信息。
