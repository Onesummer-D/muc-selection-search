# 第一周验收证据

角色 A、B、C 分别把可公开且已脱敏的日志、截图、评测结果或说明放入对应目录。原始海报、账号、Cookie、Session、API Key、真实姓名、未脱敏数据库和包含本机绝对路径的文件不得提交。

录屏等大文件不直接提交仓库。A、B先在各自的 `progress/week1/<角色>/PROGRESS.md` 或 PR 清单中登记共享链接、PR 或 GitHub 附件地址；C是 `docs/week1/05_本周验收台账.xlsx` 的唯一提交者，负责每日回填“证据索引”和“协作交接”。

多模态评测证据还必须记录服务商、模型版本、实际发送的数据类型、授权依据、价格日期、供应商保留策略和脱敏检查。未确认外部处理边界前不得上传原始个人海报。
