# 第二周接口与数据字典

基线：`feat/week2-integration`，日期 2026-09-21 至 2026-09-27。接口继续使用 Flask 后端权限判断，前端不自行决定可见性。B 评测在本周以归一化口径作为验收主口径，严格逐样本结果仍保留为审计附件。

## 用户与隐私

| 方法 | 路径 | 约束 | 成功响应 |
|---|---|---|---|
| GET/POST/DELETE | `/api/saved-searches` | 仅校内登录；只接收白名单 `query_plan`；提醒仅 `off/daily/weekly`，默认 `weekly` | 列表/201/删除摘要 |
| PATCH | `/api/saved-searches/{id}/alert` | 只能修改自己的记录 | 保存搜索 DTO |
| GET/PATCH | `/api/me/privacy` | `history_enabled`、`recommendation_enabled`；默认 false | 设置与固定 `retention_days=90` |
| DELETE | `/api/me/history` | 只删除当前用户 | 删除行数 |
| GET | `/api/me/insights` | 推荐关闭时返回空 insights | 画像摘要或空对象 |
| GET | `/api/notifications` | 只读当前用户站内提醒 | 通知列表 |

保存搜索的数据结构是 `query_plan`，字段仅 `cohort/education/college/major/city/position_or_unit/keywords/page/page_size`。自然语言原文、Cookie、CAS ticket 和私有字段不入表。

## 无痕规则

请求头 `X-Incognito-Mode: 1` 时，后端不得写入 `search_history`，也不得写入筛选、点击、对比、导出或推荐信号。已有历史不因一次无痕请求被删除。

## 发布状态

`POST /api/admin/records/{record_key}/publish` 与 `/withdraw` 仅管理员可用，写入 `processing_events` 审计事件。B 导入不会覆盖既有 `visibility`；`review_required` 默认不公开。

## 身份边界

开发验收可在 `ENABLE_DEV_ROLE_SWITCH=true` 下使用 `/api/dev/role`，并用 `X-Demo-User` 区分测试用户。生产必须由 CAS/SSO 适配器提供 subject，不能把客户端 header 当成认证凭据。
